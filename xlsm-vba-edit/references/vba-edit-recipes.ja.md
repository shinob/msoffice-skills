# VBA 編集レシピ

[English](vba-edit-recipes.md)

AI と VBA を編集するときに使うプロンプト例です。

## 分析プロンプト

```text
msoffice-skills を使って @{xlsm_file} を分析してください。

VBA を書き出し、{xlsm_file}_analysis.md に以下をまとめてください。
1. ブック概要: シート、モジュール、主要機能。
2. 優先度別の問題:
   - High: バグ・クラッシュリスク。
   - Medium: 未完成または壊れている機能。
   - Low: 保守性・コード品質。
3. 各問題の場所、内容、修正方針、必要ならコード例。
4. 推奨修正順と検証チェックリスト。
```

## 機能計画プロンプト

```text
msoffice-skills を使って @{xlsm_file} の現状機能を確認してください。

その後、追加したい機能について以下をヒアリングしてください。
1. 目的と利用場面。
2. 操作方法: メニュー、ボタン、イベント、自動実行など。
3. 優先度と期限。

結果を {xlsm_file}_features.md にまとめてください。
```

## 修正適用プロンプト

```text
@{xlsm_file}_analysis.md を確認し、選択した修正を @{xlsm_file}_VBA/ 内の対象ファイルに適用してください。

完了後、変更ファイル、変更概要、VBE 貼り付け手順を報告してください。
```

## 確認プロンプト

```text
VBE への貼り付けと保存が完了しました。
export_vba.py で再書き出しし、編集済みファイルと比較してください。
意図した変更のみが反映されているか報告してください。
```
