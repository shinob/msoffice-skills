# DOCX テキスト編集レシピ

[English](text-edit-recipes.md)

## レシピ 1: 1 つの run 内の文字列を置換

対象文字列が 1 つの `<w:t>` 内にある場合は、そのテキストノードだけを置換します。周辺の `w:rPr`、段落プロパティ、relationship ID は変更しません。

## レシピ 2: 複数 run に分かれた文字列を置換

語句が複数 run に分かれている場合は、書式を保持したまま各 `w:t` を必要最小限変更します。run を統合する場合は、書式が変わることを確認してから行います。

## レシピ 3: ヘッダー・フッター・脚注・コメント

同じ語句が複数箇所にある場合は、本文だけか、ヘッダーやコメントも含むかを確認します。

## レシピ 4: プレースホルダー削除

```bash
python3 docx-text-ops/scripts/extract.py working_copy.docx | grep -iE "xxxx|lorem|ipsum|tbd|placeholder"
```

検出された箇所を意図的に編集し、再梱包後に同じ grep で残存を確認します。

## レシピ 5: 翻訳

全文抽出を基準として保存し、本文以外の範囲が対象か確認してから、XML のテキストノードを面ごとに処理します。テキストボックスや狭い表セルでは長さに注意します。

## 検証

- 古いテキストが残っていない。
- 新しいテキストが正しい。
- プレースホルダーが残っていない。
- 意図しないヘッダー、フッター、脚注、コメント変更がない。
